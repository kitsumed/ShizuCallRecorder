# Introduction
## Why was this project originally started?
Ever release of Android 4.4 KitKat (API 19) / Android 6, native 3rd-party phone call recording apps have been [killed](https://issuetracker.google.com/issues/37127141) for valid [privacy](https://issuetracker.google.com/issues/137210607#comment8) reasons, with
no [visible effort](https://issuetracker.google.com/issues/128677410) from Android/Google in the following years to provide developers with [any compromises or runtime permissions](https://issuetracker.google.com/issues/112602629). In fact, in the following years, they kept closing work-around developers had founds to bypass the restrictions.

In an Android 11 development build, they created and new permission [`ACCESS_CALL_AUDIO`](https://web.archive.org/web/20240803000244/https://developer.android.com/sdk/api_diff/r-dp2/changes/android.Manifest.permission) and accorded it to the default phone dialer (still limited but better than nothing) that would allow call recording, only to [quickly revert](https://issuetracker.google.com/issues/158923887) it while claiming, "[Feature has been postponed](https://android.googlesource.com/platform/frameworks/av/+/57a3769fb12dc8b2df457e0919850bd976716706) [...] [we're not doing this in R](https://android.googlesource.com/platform/packages/apps/PackageInstaller/+/d67ba72fbe34573ec5b5e88ddfd3ef1086922d7b)"

Meanwhile, proprietary apps like the Google Dialer and OEM apps can use the restricted system/signature permission `CAPTURE_AUDIO_OUTPUT`, and some do have the recording feature. However, **they often choose not to offer it to most users**, or **they add their own proprietary rules and restrictions** on top of it, even if it is legal in the user country. Their apps are also **often privacy invasive** with telemetry or tracking in general.

On the other hand, the few closed-source third-party alternatives that still exists are often unreliable and use workarounds like recording the call audio via the microphone with maximum sensitivity, which results in poor audio quality and no Bluetooth support. They have ads, agressive popups, subscriptions, and very invasive permissions, which is a perfect combo to compromise one's privacy and a goldmine of data for data brokers.

During all of this time, I, **kitsumed**, would sometimes wander off on the internet for a couple of hours, hoping to find a free and privacy-friendly application that would finally let me record calls. However, every time, I could not find any. Little by little, I started thinking about creating my own, and one day, for some reason, I actually tried, failed, and then got a very ugly prototype working. From there, I rewrote that prototype into my first real Android application over a couple of months, [released `v1.0.0`](https://www.reddit.com/r/fossdroid/comments/1tgxi0e/shizucallrecorder_record_phone_call_on_android/), and kept improving the project to where it is now. You can find a more detailed story [here](https://github.com/kitsumed/ShizuCallRecorder/blob/main/CONTRIBUTING.md#the-origins-of-this-project).

This project uses the same permissions as Google/OEM proprietary apps. We managed to do this via ADB, which allows us to run code as the shell application. It holds [special system permissions](https://cs.android.com/search?q=com.android.shell%20file:%2Fpackages%2FShell%2FAndroidManifest.xml). It has a few downsides, and I wish it didn't, but that's the best we can do when Google/AOSP refuses to let developers do what they want with their devices.

We use ADB (currently via Shizuku). **I would recommend you read [Shizuku About Page](https://github.com/thedjchi/Shizuku/wiki/About) wiki to have a very basic understanding** of why we need this.
If you are curious about the security aspects and how it works in more detail, you can read my blog post: **[What Is Shizuku? How Does It Work? Security Implications?](https://kitsumed.github.io/blog/posts/what-is-shizuku_how-does-it-work_security-implications/)**.  

Even if you do not understand everything, it will give you a basic, general understanding of why we must use it and what it allows us to do. This is probably a lot to read, but it's a one-time thing.
